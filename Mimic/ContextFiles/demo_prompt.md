```
Create a joyful childhood memory edit that feels like rediscovering

Gradually build through playful and candid moments.

Around the musical swell transition into a Peak where joyful moments

prioritize different clips so the montage feels rich and varied.

End with a warm emotional moment that lingers.

The edit should feel soft, warm, and full of innocent happiness.
```
